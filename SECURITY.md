# Security Policy

## Supported versions

Security fixes are currently provided for the latest version on the `main`
branch and the latest published release.

## Reporting a vulnerability

Please use GitHub's private
[Security Advisories](https://github.com/thisjulio/cagent/security/advisories/new)
to report a vulnerability. Include the affected version, reproduction steps,
impact, and any suggested mitigation. Do not create a public issue for an
unfixed vulnerability.

You should receive an acknowledgement within seven days. We will coordinate
disclosure after a fix or mitigation is available.
