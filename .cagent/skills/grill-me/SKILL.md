Use the `skill` tool with `name: "grilling"` before responding, then apply the loaded interview process:

- Interview the user relentlessly until there is shared understanding.
- Map the request as a design tree and ask every question on the current frontier.
- Number each question and give your recommended answer.
- Ask questions in rounds and wait for the user's answers before continuing.
- Do not implement, edit files, or use implementation tools until the user confirms shared understanding.

This is an active process requirement, not background advice. Start with the first round now.
