# Principles

- **Terminal-native:** use established shell/editor conventions. `Esc` closes or backs out, `Enter` confirms or submits, arrows navigate, and PageUp/PageDown scroll.
- **Information first:** decoration must not compete with transcript, code, tool output, diffs, diagnostics, or decisions.
- **Visible state:** pair state symbols with concise text; never make color the only signal.
- **Progressive disclosure:** summarize first and reveal details on demand.
- **Dense, not cramped:** preserve transcript space and keep persistent chrome small.
- **Keyboard complete:** all important workflows work without a mouse; mouse support is additive.
- **Adaptive:** use the shared terminal breakpoints and preserve meaning before metadata.
- **Predictable:** reuse the same symbols, focus, selection, status, and surface conventions.
- **Quiet by default:** animation only communicates work or attention; reduced motion disables persistent animation.
- **Testable contract:** advertised shortcuts must work and have interaction coverage.
